# Microsoft Store Release

Openza Reader is live on the Microsoft Store:

- https://apps.microsoft.com/detail/9NNPMN0JSSW5?hl=en-us&gl=IN

Store distribution avoids self-signed installer friction because Microsoft signs the submitted MSIX package and handles trusted install/update delivery.

## Partner Center Steps

These steps require the project owner's Microsoft Partner Center account:

1. Create or open a Partner Center developer account.
2. Reserve the app name `Openza Reader`.
3. Restore the Avalonia project for the Windows x64 runtime.
4. Create the Release x64 Store package with `eng\package-windows.ps1 -Store`.
5. Upload the generated unsigned `.msix` package in Partner Center.
6. Complete Store listing, age rating, pricing, privacy, and support fields.
7. Submit for certification.
8. After certification completes, verify the public Store listing and install path.

## Package Notes

- Target: Windows 10 22H2 and Windows 11.
- Minimum package version: `10.0.19045.0`.
- Avalonia replacement candidate version: `1.2.0.0`.
- Architecture: x64 for V1.
- Package type: self-contained MSIX generated by the repository packaging script and Windows SDK `MakeAppx.exe`.
- Store signing: handled by Microsoft Store after submission.
- Runtime: build and package as self-contained for normal user installs.
- Renderer: fully managed `Avalonia.HtmlRenderer`; the replacement package has no WebView2 or WebKit runtime dependency.
- Local test signing keys such as `Openza.Reader_TemporaryKey.pfx` must never be committed.
- Production identity: `Openza.OpenzaReader`, publisher `CN=DAC3BFD1-0B27-4912-85AF-DB96E18108D1`, application ID `App`.
- Development identity: `Openza.OpenzaReader.Avalonia.Dev`; it can coexist with the Store release.
- First packaged launch migrates the existing WinUI LocalSettings values and recents into the Avalonia settings file.

## Build Commands

```powershell
dotnet restore src/Openza.Reader.Avalonia/Openza.Reader.Avalonia.csproj -r win-x64
.\eng\package-windows.ps1 -Architecture x64 -Version 1.2.0.0
.\eng\package-windows.ps1 -Architecture x64 -Version 1.2.0.0 -Store
```

The generated packages are ignored under `artifacts\windows\win-x64\dev` and `artifacts\windows\win-x64\store`. Never commit signing material or generated MSIX files.

## Release Smoke Test

- Build both development and Store-identity Release x64 packages.
- Register or sign/install the separate development package locally.
- Open the app from Start.
- Open `.md` and `.markdown` files from File Explorer.
- Confirm file association.
- Confirm drag and drop.
- Confirm TOC, search button, Preview/Raw/Side by side modes, settings persistence, recents, themes, remote image policy, zoom, copy, reload, and external editor actions.
- Confirm the packaged manifest uses `MinVersion="10.0.19045.0"`.
- Confirm the Store manifest retains identity `Openza.OpenzaReader` and application ID `App`.
- Confirm an upgrade test preserves settings and recent files from the installed WinUI release.
- Open the WinUI release and packaged Avalonia candidate side by side with the same document; compare full-width, narrow-width, themes, High Contrast, toolbars, workspaces, search, TOC, focus mode, and document statistics.
- Confirm uninstall removes the app cleanly.
