# Microsoft Store Release

Openza Reader is live on the Microsoft Store:

- https://apps.microsoft.com/detail/9NNPMN0JSSW5?hl=en-us&gl=IN

Store distribution avoids self-signed installer friction because Microsoft signs the submitted MSIX package and handles trusted install/update delivery.

## Partner Center Steps

These steps require the project owner's Microsoft Partner Center account:

1. Create or open a Partner Center developer account.
2. Reserve the app name `Openza Reader`.
3. Associate the Visual Studio project with the reserved Store app.
4. Create a Release x64 package using **Publish > Create App Packages** and the **Microsoft Store** option.
5. Upload the generated `.msixupload` package in Partner Center.
6. Complete Store listing, age rating, pricing, privacy, and support fields.
7. Submit for certification.
8. After certification completes, verify the public Store listing and install path.

## Package Notes

- Target: Windows 10 22H2 and Windows 11.
- Architecture: x64 for V1.
- Package type: MSIX upload package generated by Visual Studio.
- Store signing: handled by Microsoft Store after submission.
- Local test signing keys such as `Openza.Reader_TemporaryKey.pfx` must never be committed.
- Visual Studio association with the Store app will update package identity values assigned by Partner Center.

Openza Reader focuses on clean, safe reading. Markdown is treated as untrusted input, raw HTML is escaped, scripts are blocked by construction, and external navigation is handled through the system browser.

## Release Smoke Test

- Build Release x64 package.
- Install package locally from Visual Studio.
- Open the app from Start.
- Open `.md` and `.markdown` files from File Explorer.
- Confirm file association.
- Confirm drag and drop.
- Confirm TOC, search, zoom, copy, reload, and external editor actions.
- Confirm uninstall removes the app cleanly.
