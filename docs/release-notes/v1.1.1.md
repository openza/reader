# Openza Reader 1.1.1

Openza Reader 1.1.1 is the next planned Microsoft Store update for Openza Reader.

Install and updates remain available through the Microsoft Store:

- https://apps.microsoft.com/detail/9NNPMN0JSSW5?hl=en-us&gl=IN

GitHub Releases are used for source snapshots and release notes. No unsigned or self-signed standalone MSIX package is planned for this release.

## Highlights

- Fixes Google Drive-hosted Markdown documents failing to render with `ERR_FILE_NOT_FOUND` by storing rendered HTML in the app-managed local cache.
- Separates the development package identity from the Microsoft Store identity so local development can coexist safely with the installed Store app.
- Refreshes public documentation, licensing guidance, and the open-source security baseline.

## Release Validation

- Automated validation passed on August 8, 2026: 11 tests, a Release app build with zero warnings or errors, and a `gitleaks` scan with no findings.
- The generated package must use version `1.1.1.0` and preserve the Store identity `Openza.OpenzaReader`.
- Google Drive document rendering must pass a manual smoke test.
- Clean-machine validation without .NET 10 (#12) is explicitly deferred because the required environment is not currently available.
- Missing or broken WebView2 Runtime validation (#14) is explicitly deferred for the same reason.

## Requirements

- Windows 10 22H2 or later, or Windows 11.
- x64 architecture for this release.
