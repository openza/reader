# Openza Reader 1.1.0

Openza Reader 1.1.0 is the current Microsoft Store update for Openza Reader.

Install and updates remain available through the Microsoft Store:

- https://apps.microsoft.com/detail/9NNPMN0JSSW5?hl=en-us&gl=IN

GitHub Releases are used for source snapshots and release notes. No unsigned or self-signed standalone MSIX package is planned for this release.

## Highlights

- Preview, Raw Markdown, and Side by side read-only view modes.
- Visible toolbar labels and improved command order for reading workflows.
- Recent files screen, plus a toolbar Recent command while a document is open.
- Native Settings and About workspaces designed for desktop layouts.
- Reader themes: System, Light, Dark, and Sepia.
- Document stats: word count, estimated read time, and heading count.
- Immersive focus mode with visible exit affordance and Esc/F11 support.
- External editor picker that uses installed Windows apps for Markdown files.
- Remote image privacy setting.
- Improved wide-table rendering and horizontal table scrolling.
- WebView2 missing-runtime error with an official install/repair link.

## Requirements

- Windows 10 22H2 or later, or Windows 11.
- x64 architecture for this release.
