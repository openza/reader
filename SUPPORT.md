# Support

Openza Reader is a public Microsoft Store app and an open-source Windows Markdown reader.

Use GitHub issues for:

- Bugs
- Accessibility problems
- Packaging/install issues
- Small V1 feature requests

Before opening an issue, please search existing issues and include:

- Windows version
- Openza Reader version or commit
- How the app was installed or launched
- A minimal Markdown sample when the issue is rendering-related

Security vulnerabilities should follow `SECURITY.md` instead of public issues.
