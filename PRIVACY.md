# Privacy Policy

Openza Reader is a local Markdown reading app for Windows.

## Data Collection

Openza Reader does not collect, sell, or transmit personal data to Openza.

The app opens Markdown files selected by the user, renders them locally, and stores WebView2 runtime data in the app's local Windows package storage. That storage is managed by Windows and WebView2.

## Network Access

Markdown documents may reference remote images or links. If a document contains a remote image URL, WebView2 may request that image from the remote server so the document can render as authored. External web links open in the user's default browser.

Openza Reader does not send Markdown file contents to Openza services.

## Local Files

Local images referenced by Markdown are loaded from paths relative to the opened Markdown file. The app does not upload local files.
