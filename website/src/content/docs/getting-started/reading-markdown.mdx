# Reading Markdown

Openza Reader is designed around a simple reading workflow.

## Open A File

You can open Markdown files by:

- Using the Open button in the app
- Dragging a `.md` or `.markdown` file into the window
- Opening a Markdown file from File Explorer after the app is installed with file associations

## Navigate

The table of contents is generated from headings in the Markdown document. Select a heading to jump to that section.

## Choose A View

Use Preview for the rendered reading surface, Raw for selectable read-only Markdown text, or Side by side to compare both views.

## Search

Use the app search command to find text in the rendered document. Search is implemented through WebView2's native Find API.

## Zoom And Copy

Use zoom controls to adjust the reading size. Select rendered text and copy it from the toolbar or keyboard shortcut.

## External Editor

Openza Reader stays read-only. Use the Editor command when you want Windows to show installed apps that can edit the current Markdown file.

## Settings And Recents

Settings include default view mode, reader theme, remote image policy, document stats, and recent file controls. Recent files stay local to the current Windows account.
