# Welcome to Openza Reader

Openza Reader is a Windows-first Markdown reader for people who want to open `.md` and `.markdown` files quickly, read them comfortably, and avoid accidental edits.

It is intentionally small: open a file, render it safely, navigate headings, search text, adjust zoom, and return to your work.

## What It Does

<CardGrid stagger>
  <Card title="Opens Markdown Files" icon="document">
    Open files from the app, by drag and drop, or through Windows file association.
  </Card>
  <Card title="Shows Document Structure" icon="list">
    A table of contents is generated from Markdown headings.
  </Card>
  <Card title="Keeps Reading Comfortable" icon="eye">
    Typography, zoom controls, and rendered-selection copy are tuned for reading.
  </Card>
  <Card title="Reloads Automatically" icon="refresh">
    Changed files can be reloaded with a debounce while preserving your approximate position.
  </Card>
</CardGrid>

## V1 Scope

Openza Reader V1 is an MVP focused on Markdown reading. Editing, tabs, export, Mermaid, math rendering, plugins, sync, accounts, and AI features are intentionally out of scope.

## Status

Openza Reader is live on the Microsoft Store; developers can build and run it from source too.
