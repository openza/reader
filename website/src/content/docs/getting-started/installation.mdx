# Installation

Openza Reader is available from the Microsoft Store. Developers can also build and run it from source.

## Install From Microsoft Store

[Install Openza Reader from the Microsoft Store](https://apps.microsoft.com/detail/9NNPMN0JSSW5?hl=en-us&gl=IN)

## Requirements

- Windows 10 22H2 or later, or Windows 11
- .NET 10 SDK
- Visual Studio 2026 Community or later with WinUI application development tools
- Windows App SDK 2.0.x workload

Microsoft's WinUI development configuration can install the required Visual Studio workload:

```powershell
winget configure -f https://aka.ms/winui-config
```

## Run From Source

Clone the repository:

```powershell
git clone https://github.com/openza/reader.git
cd reader
```

Restore, test, and build:

```powershell
dotnet restore src/Openza.Reader.Tests/Openza.Reader.Tests.csproj
dotnet test src/Openza.Reader.Tests/Openza.Reader.Tests.csproj -c Release --no-restore
dotnet build src/Openza.Reader/Openza.Reader.csproj -c Release --no-restore
```

For packaged debugging, open the solution in Visual Studio and ensure Deploy is enabled in Configuration Manager.

## Installer Status

V1 uses Microsoft Store distribution first. The Store signs the package and provides the trusted install/update path for public users.

A winget package can follow after verifying the live Store listing and package identity.
