## Features

<CardGrid stagger>
  <Card title="Native Windows Experience" icon="laptop">
    A modern WinUI 3 interface built for Windows 10 and Windows 11, packaged with MSIX.
  </Card>
  <Card title="Focused Markdown Reading" icon="open-book">
    Open Markdown files quickly in a clean reading surface with typography, zoom, and copy support.
  </Card>
  <Card title="Safe Rendering" icon="shield">
    Markdown is treated as untrusted input. Raw HTML is escaped and navigation is intercepted.
  </Card>
  <Card title="Reader Controls" icon="magnifier">
    Use table of contents navigation, search, zoom, reload, copy, and external editor actions.
  </Card>
</CardGrid>
