## Features

<CardGrid stagger>
  <Card title="Read-Only by Design" icon="open-book">
    Open Markdown files quickly without turning the reading surface into an editor.
  </Card>
  <Card title="Native Windows App" icon="laptop">
    Built with WinUI 3, Windows App SDK, WebView2, and MSIX packaging.
  </Card>
  <Card title="Safe Rendering" icon="shield">
    Markdown is treated as untrusted input. Raw HTML is escaped and navigation is intercepted.
  </Card>
  <Card title="Reader Controls" icon="magnifier">
    Use table of contents navigation, search, zoom, reload, copy, and external editor actions.
  </Card>
</CardGrid>
