# Security Model

Openza Reader treats Markdown files as untrusted content.

## Rendering Rules

- Raw HTML is disabled in Markdig.
- Markdown-provided scripts and inline event handlers are blocked by construction.
- Generated HTML is wrapped in an app-owned document shell.
- Bundled scripts are limited to local reader behavior and code highlighting.

## WebView Rules

- Host objects are disabled.
- Web messages are disabled unless a narrow internal command channel becomes necessary later.
- Script dialogs are disabled.
- Navigation is intercepted.

## Link Handling

- Heading anchors stay inside the document.
- `http`, `https`, and `mailto` links open externally.
- `javascript:`, arbitrary `file:`, and unknown schemes are blocked.
- Local images resolve relative to the opened Markdown file.
- Remote images are allowed for README compatibility.

## Future HTML Compatibility

If raw HTML support is added later, it should be allowlist-sanitized before reaching the WebView.
