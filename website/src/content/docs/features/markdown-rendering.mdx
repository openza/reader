# Markdown Rendering

Openza Reader renders Markdown through Markdig and displays the generated HTML inside an app-owned WebView2 shell.

## Supported V1 Features

- Headings with stable IDs
- Lists
- Tables
- Task lists
- Fenced code blocks
- Blockquotes
- Links
- Local and remote images

## Code Highlighting

Reader bundles small Prism-compatible highlighting assets locally. There is no CDN dependency at runtime.

## Raw HTML

Raw HTML inside Markdown files is disabled in V1. HTML-like input is escaped and displayed as text instead of being interpreted by the WebView.

Limited sanitized HTML compatibility may be considered later, but it is not part of V1.
